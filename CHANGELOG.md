# Changelog

All notable changes follow semantic versioning.

## [0.1.0] - 2026-09-19

### Added

- ISO C17 recursive-descent evaluator for decimal arithmetic expressions.
- Command-line interface with stable diagnostics and exit codes.
- Unity/CTest unit and black-box integration tests.
- Strict cross-platform builds for Linux x86-64/ARM64, Windows x86-64, and macOS ARM64.
- clang-format, cppcheck, ASan, UBSan, CodeQL, and evaluator coverage gates.
- Automated tagged release archives and SHA-256 checksums.
